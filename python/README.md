# Analyses Python — Rénovation énergétique à Nantes

Ce dossier regroupe les scripts Python et les notebooks Jupyter utilisés dans le projet final Data Analyst & IA.

## Objectifs

Explorer les données des diagnostics de performance énergétique (DPE) de Nantes.

Contrôler la qualité et la cohérence des données.

Préparer et nettoyer les données avec Pandas.

Rattacher géographiquement les diagnostics aux 11 quartiers de Nantes à l'aide de GeoPandas.

Préparer les fichiers destinés aux analyses Power BI.

## Outils utilisés

- Python / Pandas : exploration, nettoyage et préparation des données.
- GeoPandas : traitement des données géographiques.
- Jupyter Notebook : documentation des analyses et des traitements.

## Fichiers du projet

- 02_exploration_dpe_nantes.ipynb : notebook d'exploration des données DPE.

- verification_colonnes_dpe.py : vérification des colonnes.

- verification_quartiers.py : contrôle du rattachement aux quartiers.

## Méthodologie

Les traitements Python complètent les contrôles effectués avec MySQL et permettent de préparer des données cohérentes pour les tableaux de bord Power BI.

Les scripts et notebooks seront ajoutés progressivement à ce dossier.
