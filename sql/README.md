# Analyses SQL — Rénovation énergétique à Nantes

Ce dossier regroupe les requêtes MySQL utilisées dans le projet final Data Analyst & IA.

## Objectifs

- Contrôler la qualité et la cohérence des données DPE.
- Analyser la répartition des diagnostics par type de logement.
- Étudier les classes énergétiques A à G.
- Comparer les maisons individuelles et les appartements.
- Vérifier les indicateurs utilisés dans Power BI.

## Méthodologie

Les requêtes SQL permettent de contrôler les résultats et de fiabiliser les indicateurs avant leur exploitation dans les tableaux de bord décisionnels.

Les scripts SQL seront ajoutés progressivement à ce dossier.
